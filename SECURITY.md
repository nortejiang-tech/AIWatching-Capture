# Security policy

Please do not open a public issue for a potential security or privacy vulnerability.

Report it privately to the repository owner with:

- affected source path and commit SHA;
- a minimal reproduction that contains no recording, credential, or personal data;
- the impact and any safe mitigation you have identified.

This repository must never receive real audio, session exports, signing material, API keys, browser profiles, or device backups in issues, pull requests, tests, or examples.
